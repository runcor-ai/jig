# Snake (React + TypeScript + Vite)

Client-only Snake on a 20x20 grid. Rules are pure functions in `src/game/logic.ts`; React only renders and drives the timer.

## Setup
    npm install

## Run
    npm run dev

Controls: arrows or WASD to steer, Space to pause/resume.

## Test
    npx vitest run

## Build
    npm run build

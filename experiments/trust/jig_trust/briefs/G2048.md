# 2048

A browser sliding-tile number game on a 4 x 4 grid.

- The arrow keys slide every tile as far as possible in that direction. Two tiles with the same number that
  collide merge into one tile with their sum. A tile made by a merge cannot merge again in the same move.
- After every move that changed the grid, a new tile (2, or sometimes 4) appears in a random empty cell. The
  game starts with two tiles.
- The score goes up by the value of every merged tile. The game is over when no move can change the grid. Show
  the score and a New game button.

## Required game logic: `src/logic.ts`

All game rules must live in `src/logic.ts` as pure functions with exactly these named exports. The page must
use them (the page adds the random new tiles itself). They must not touch the DOM.

```ts
export type Grid = number[][];                  // 4 rows of 4 numbers; 0 means empty
export type Dir = 'left' | 'right' | 'up' | 'down';

export function slideRow(row: number[]): { row: number[]; score: number };
export function move(grid: Grid, dir: Dir): { grid: Grid; score: number; moved: boolean };
export function canMove(grid: Grid): boolean;
```

- `slideRow(row)` slides one row to the **left**: tiles move left past empty cells, equal neighbours merge once
  per move (the pair nearest the left edge merges first, so `[2, 2, 2, 0]` gives `[4, 2, 0, 0]`), and the row
  keeps its length, padded with 0. `score` is the sum of the merged tiles' new values.
- `move(grid, dir)` applies the slide in direction `dir` to every row or column and returns a **new** grid (it
  must not change `grid`), the score gained, and `moved` = whether anything changed. It never adds a new tile.
- `canMove(grid)` is `true` if any move in any direction would change the grid.
